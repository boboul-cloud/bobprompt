Comment pouvons-nous vous aider ?

Questions fréquentes

📜 Comment utiliser le téléprompteur ?

Entrez ou collez votre texte, puis appuyez sur le bouton "Lire". Le texte défilera automatiquement. Utilisez les contrôles pour ajuster la vitesse ou mettre en pause.

🪞 Comment activer le mode miroir ?

Appuyez sur le bouton "Miroir" dans la barre d'outils en bas de l'écran. Le texte sera inversé horizontalement, idéal pour une utilisation avec un vrai téléprompteur.

🎨 À quoi servent les syllabes colorées ?

Cette fonctionnalité alterne les couleurs des syllabes pour faciliter la lecture, particulièrement utile pour les enfants ou les personnes ayant des difficultés de lecture.

💾 Comment sauvegarder mes textes ?

Appuyez sur le bouton "Textes" pour accéder à votre bibliothèque. Vous pouvez y sauvegarder et organiser vos scripts. Note : la version gratuite est limitée à 2 textes.

🤖 Comment utiliser la génération IA ?

Appuyez sur le bouton IA (étoiles). Vous devrez entrer votre propre clé API OpenAI dans les paramètres. Décrivez ensuite le contenu souhaité et l'IA le générera pour vous.

🔑 Où obtenir une clé API OpenAI ?

Rendez-vous sur platform.openai.com, créez un compte, puis générez une clé API. Des frais peuvent s'appliquer selon votre utilisation.

👑 Comment passer à Premium ?

Appuyez sur la bannière "Passez Premium" ou sur le badge Premium pour accéder à la page d'achat. L'achat est unique et débloque toutes les fonctionnalités à vie.

🔄 Comment restaurer mes achats ?

Allez dans la page Premium et appuyez sur "Restaurer mes achats". Assurez-vous d'être connecté avec le même compte Apple utilisé lors de l'achat initial.

Conseils d'utilisation

💡 Astuce : Pour une meilleure lisibilité lors de vos présentations, augmentez la taille du texte et choisissez un thème avec un bon contraste.

💡 Astuce : Utilisez le compte à rebours (3-2-1) pour vous préparer avant que le défilement ne commence.

Problèmes techniques

L'application ne répond plus

Fermez complètement l'application et relancez-la. Si le problème persiste, essayez de redémarrer votre appareil.

Mes textes ont disparu

Les textes sont stockés localement. Si vous avez désinstallé l'application, les données peuvent avoir été supprimées. Malheureusement, nous ne pouvons pas les récupérer.

L'achat Premium ne fonctionne pas

Vérifiez votre connexion internet et réessayez. Si le problème persiste, essayez de restaurer vos achats ou contactez le support Apple.
