Politique de Confidentialité

bobprompt - Application iOS

Introduction

Bienvenue sur bobprompt. Nous accordons une grande importance à la protection de votre vie privée. Cette politique de confidentialité explique comment nous traitons vos données lorsque vous utilisez notre application.

Données collectées

bobprompt est conçu avec le respect de votre vie privée comme priorité :

  • Stockage local uniquement : Tous vos textes et paramètres sont stockés localement sur votre appareil.
  • Pas de compte utilisateur : Aucune inscription n'est requise pour utiliser l'application.
  • Pas de collecte de données personnelles : Nous ne collectons pas votre nom, email, ou autres informations personnelles.

Clé API OpenAI

Si vous utilisez la fonctionnalité de génération de contenu par IA :

  • Votre clé API OpenAI est stockée de manière sécurisée dans le Keychain de votre appareil.
  • La clé est utilisée uniquement pour communiquer directement avec les serveurs d'OpenAI.
  • Nous n'avons jamais accès à votre clé API.
  • Les requêtes sont envoyées directement à OpenAI selon leurs conditions d'utilisation.

Achats In-App

Les achats in-app sont gérés par Apple via l'App Store :

  • Nous ne collectons pas vos informations de paiement.
  • L'état de votre abonnement Premium est stocké localement.
  • Apple gère toutes les transactions financières.

Analytiques

bobprompt n'intègre aucun outil d'analyse tiers. Nous ne suivons pas votre utilisation de l'application.

Partage de données

Nous ne vendons, n'échangeons ni ne transférons vos données personnelles à des tiers. Vos textes restent privés sur votre appareil.

Sécurité

Nous utilisons les meilleures pratiques de sécurité iOS :

  • Stockage sécurisé via le Keychain pour les données sensibles.
  • Aucune transmission de données vers nos serveurs.
  • L'application fonctionne entièrement hors ligne (sauf pour la génération IA).

Droits des utilisateurs

Vous pouvez à tout moment :

  • Supprimer tous vos textes depuis l'application.
  • Supprimer votre clé API des paramètres.
  • Désinstaller l'application pour supprimer toutes les données.

Modifications

Nous pouvons mettre à jour cette politique de confidentialité. Les modifications seront publiées sur cette page avec une nouvelle date de mise à jour.
